Tìm bài viết Facebook xếp hạng cao trên Google trùng khớp với nội dung truyện

Cấu hình API tìm kiếm Google

Tool dùng API chính thức để lấy kết quả Google (đúng thứ tự như khi bạn tự tìm trên google.com). Khuyên dùng Serper.dev: đăng ký tại serper.dev, có 2.500 lượt tìm miễn phí, copy API key dán vào đây.

Tool lấy đoạn mở đầu truyện, tìm trên Google giống như bạn copy đoạn đó dán vào google.com, rồi chọn bài Facebook xếp cao nhất có nội dung khớp truyện.
